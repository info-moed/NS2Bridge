# Getting help

1. **Check the docs first:** [Troubleshooting](docs/reference/troubleshooting.md),
   [FAQ](docs/reference/faq.md), and the [install guide](docs/INSTALL.md), including first launch and uninstalling.
2. **Questions, ideas, show-and-tell:** [GitHub Discussions](https://github.com/info-moed/NS2Bridge/discussions).
3. **Something broken:** open a [bug report](https://github.com/info-moed/NS2Bridge/issues/new/choose) and attach
   a diagnostics report (Diagnostics tab → *Export Diagnostics Report…*). It contains no serial numbers, addresses or
   personal paths.
4. **A game or emulator worked or didn't:** a
   [compatibility report](https://github.com/info-moed/NS2Bridge/issues/new/choose) helps everyone.
5. **Security problems:** see [SECURITY.md](SECURITY.md). Please don't post them publicly.

NS2 Bridge is a volunteer project; replies may take a few days.
