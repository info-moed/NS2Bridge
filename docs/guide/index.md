# User guide

NS2 Bridge lives in the menu bar and has one window with a tab per tool. The chips across the top of the window
are the connected controllers (P1, P2, …); the tools act on the one you pick.

**Basic** mode shows the everyday tabs: Players & Profiles, Controller, Calibrate Sticks, Haptics, Games, Wireless,
Battery and Setup. **Advanced** adds Button Test, Motion, Latency Test and Diagnostics. Switch at the bottom of the
sidebar or in Setup.
